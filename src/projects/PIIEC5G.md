# PIIEC 5G 

The European PIIEC ME/CT project (Project of Common European Interest in Microelectronics and Information Technology) aims to pave the way for the 5G of tomorrow—with faster, smarter, and more open networks—by enabling various stakeholders (companies, researchers, universities) to work together to develop new telecommunications technologies. The main objective of the French branch of the project is to create an IT platform, based on the Sylva software stack, that enables the testing, automation, and integration of innovations for the virtualized and modular networks of the future.
